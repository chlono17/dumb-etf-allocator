# 呆萌 ETF 配置助理

Vibe Coding 作業：用 AI 協助完成的互動網頁（單一 index.html，CSS 與 JavaScript 都寫在檔案內）。

延續上一週「呆萌型 AI 長期投資助理」的構想：我用定期定額建立「自己的 ETF」，只買自己理解、願意長期追蹤的公司，不在意短期漲跌，在意公司的長期決策（擴產、新技術）以及競爭者、上下游的動態。這個網頁把那份想法變成可以操作的工具。

## 規格書

### 1. 目標與使用者
- 使用者：自己（長期定期定額、自選持股的散戶）。
- 要解決的問題：新聞太分散，常只看標題就被市場情緒影響；每個月不知道該把錢分給哪一檔。
- 設計原則：判斷由使用者做，系統負責搜尋、整理、計分與提醒；不賣出、不預測、不給買賣建議。

### 2. 需求討論紀錄（先釐清需求，再寫規格）
| 問題 | 我的選擇 | 對規格的影響 |
|---|---|---|
| 什麼時候會打開這個網站？ | 每週固定看一次 | 新聞統計期間固定為最近 7 天；提供可複製的每週週報 |
| 新聞怎麼進來、判斷由誰做？ | 網站幫我搜新聞，我選要記錄的 | 新增「搜尋新聞」，結果可一鍵帶入事件表單，判斷仍由我下 |
| 每月扣款比例怎麼算？ | 依目標比例固定分配，只微調 | 扣款比例 ＝ 目標比例 ＋ 事件微調；偏離只提醒，不改變扣款 |
| 介面風格？ | 呆萌企鵝陪伴，用對話泡泡提醒 | 頁首企鵝與對話泡泡，依狀況給一句提醒 |

### 3. 輸入
| 欄位 | 說明 |
|---|---|
| 每月定期定額（NT$） | 每月投入金額 |
| 持股清單 | 名稱、代號、產業、新聞搜尋關鍵字（英文）、目前市值（NT$）、報酬率（%）、目標比例（%），可新增與刪除 |
| 再平衡門檻 | 偏離目標幾個百分點才提醒，預設 5 |
| 新聞事件 | 日期、標題、新聞中的公司、影響哪一檔持股、與持股的關係（本身／上游／下游／競爭者）、長期判斷（長期利多／短期雜訊／長期利空）、一句話原因 |
| 採納紀錄 | 每月建議採納、不採納或未決定，並寫下理由 |

### 4. 輸出與功能（五個分頁）
1. 持股設定：即時顯示現比例、總市值、加權報酬率；目標比例不是 100% 時自動換算並提示，可一鍵正規化。
2. 新聞事件：頁面最上方的「重點」顯示每檔持股在最近 7 天的利多、雜訊、利空數量與目標微調點數；「搜尋新聞」查最近 7 天的公開新聞並可一鍵加入事件；三步驟表單記錄事件，選判斷時即時顯示會微調幾個百分點；自動列出「建議加入追蹤」的公司並標示它與哪檔持股的關係。
3. 本月配置建議：每檔持股的現比例、調整後目標、偏離、本月扣款百分比（加總一定是 100%）與金額、較上月變化，以及一句話理由。
4. 每週週報：自動產生純文字週報，可一鍵複製貼到 LINE，也可下載成 .txt。
5. 採納紀錄：記錄採納與否與理由，統計採納率，並列出「呆呆記下的偏好」。

另有歡迎說明、名詞說明與每個分頁的「這一頁要做什麼」提示。

### 5. 計算規則
1. 目標比例先換算成合計 100%。
2. 事件分數：長期利多 +1、短期雜訊 0、長期利空 −1，再乘上關係權重（本身 1.0，上游、下游、競爭者 0.6），只計算最近 7 天內的事件。
3. 目標微調：分數 × 2 個百分點，上下限 ±6，加到目標比例上（最低 0）後重新換算成 100%，稱為「調整後目標」。
4. 本月扣款比例 ＝ 調整後目標，用最大餘數法取整數確保加總 100%；金額 ＝ 每月定期定額 × 比例。
5. 偏離 ＝ 現比例 − 調整後目標。偏離超過門檻只會標紅並提醒「這一季檢視是否調整目標」，不會改變本月扣款，也不會要求賣出。

### 6. 資料來源與限制
- 新聞搜尋使用 GDELT 公開新聞資料庫的 API（不需金鑰），由瀏覽器直接查詢；以英文新聞為主，所以每檔持股可設定英文關鍵字。
- 這是第三方免費服務，偶爾會慢或暫時查不到，網頁會顯示提示，仍可手動輸入事件。
- 市值與報酬率由使用者手動填寫，不串接即時股價。

### 7. 資料保存
資料只存在瀏覽器 localStorage，沒有後端；「還原範例資料」可重置。範例數字皆為虛構。

### 8. 刻意不做
即時股價、買賣建議與價格預測、AI 自動判斷新聞好壞（判斷由使用者決定）。

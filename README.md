# 呆萌 ETF 配置助理

Vibe Coding 作業：用 AI 協助完成的互動網頁（單一 index.html，CSS 與 JavaScript 都寫在檔案內）。

延續上一週「呆萌型 AI 長期投資助理」的構想：我用定期定額建立「自己的 ETF」，只買自己理解、願意長期追蹤的公司，不在意短期漲跌，在意公司的長期決策（擴產、新技術）以及競爭者、上下游的動態。這個網頁把那份想法變成可以操作的工具。

## 規格書

### 1. 目標與使用者
- 使用者：自己（長期定期定額、自選持股的散戶）。
- 要解決的問題：新聞與財報太分散，常只看標題就被市場情緒影響；每月不知道該把錢分給哪一檔。
- 設計原則：判斷由使用者做，系統負責整理、計分與提醒；只用新資金補不足，不賣出，避免過度交易。

### 2. 輸入
| 欄位 | 說明 |
|---|---|
| 每月定期定額（NT$） | 每月投入金額 |
| 持股清單 | 名稱、代號、產業、目前市值（NT$）、報酬率（%）、目標比例（%），可新增與刪除 |
| 再平衡門檻 | 偏離目標幾個百分點才視為需要調整，預設 5 |
| 統計期間 | 起訖日期，預設最近 7 天 |
| 新聞事件 | 日期、標題、新聞中的公司、影響哪一檔持股、與持股的關係（本身／上游／下游／競爭者）、長期判斷（長期利多／短期雜訊／長期利空）、一句話原因 |
| 採納紀錄 | 每月建議採納、不採納或未決定，並寫下理由 |

### 3. 輸出與功能
1. 持股設定頁：即時顯示現比例、總市值、加權報酬率，目標比例不是 100% 時自動換算並提示，可一鍵正規化。
2. 新聞事件頁：新增與刪除事件；統計期間外的事件變灰，不影響計算；自動列出「建議加入追蹤」的公司，並標示它與哪檔持股是什麼關係。
3. 本月配置建議頁：每檔持股的現比例、調整後目標、偏離、本月扣款百分比（加總一定是 100%）與金額、較上月的變化，以及一句話理由。
4. 每週週報頁：依事件與配置自動產生純文字週報，一鍵複製，之後可貼到 LINE。
5. 採納紀錄頁：記錄採納與否與理由，統計採納率，並列出「呆呆記下的偏好」。
6. 呆萌企鵝：頁首的對話泡泡會依目前狀況給一句提醒。

### 4. 計算規則
1. 目標比例先換算成合計 100%。
2. 事件分數：長期利多 +1、短期雜訊 0、長期利空 −1，再乘上關係權重（本身 1.0，上游、下游、競爭者 0.6），只計算統計期間內的事件。
3. 目標微調：分數 × 2 個百分點，上下限 ±6，調整後重新換算成 100%。
4. 配置方式：理想市值 = 調整後目標 × （現有總市值 + 本月金額）；每檔需求 = max(0, 理想市值 − 現有市值)。需求總和大於本月金額就依需求比例分配；小於就先補足需求，剩下的依目標比例分配。這樣超配的持股本月自然是 0%，不需要賣出。
5. 百分比用最大餘數法取整數，確保加總 100%。
6. 偏離超過門檻的持股會標紅並提醒「這一季檢視一次是否調整目標」。

### 5. 資料保存
資料只存在瀏覽器 localStorage，沒有後端；「還原範例資料」可重置。範例數字皆為虛構。

### 6. 範圍外（刻意不做）
自動爬新聞、串接即時股價、買賣建議與預測。這些要用外部資料與 AI API，這次作業先專注在把判斷流程與配置邏輯做成可操作的介面。

## 使用方式
直接開啟 index.html，或到 GitHub Pages 網址操作。

本專案為課堂作業的個人記錄與練習工具，不構成任何投資建議。
